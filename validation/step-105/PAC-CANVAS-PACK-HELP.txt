Help: 
(Preview) Pack sources into an msapp file

Commands: 
Usage: pac canvas pack --sources [--msapp] [--layout] [--overwrite] [--disable-load-from-yaml]

  --sources                   Directory to sources to be packed
  --msapp                     Path to .msapp file
  --layout                    The layout to use for the sources directory. Note: 'Experimental' layout is deprecated and will be removed in a future release. Use 'SourceCode' layout for the latest supported layout.
                              Values: Experimental, SourceCode
  --overwrite                 Allow file overwrite
  --disable-load-from-yaml    When specified, disables loading the packed app from *.pa.yaml files in the 'Src' directory. Only supported with 'SourceCode' layout.
